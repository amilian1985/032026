# Cuadro en Realidad Aumentada (WebAR)

Experiencia de Realidad Aumentada interactiva basada en web utilizando **MindAR** y **A-Frame**. Al apuntar con la cámara del celular hacia el cuadro físico, se reproducirá un video interactivo superpuesto.

## 🚀 Cómo probarlo
1. Escanea el código QR del proyecto o ingresa al enlace de GitHub Pages.
2. Otorga los permisos necesarios para activar la **cámara**.
3. **Toca la pantalla una vez** para habilitar la reproducción de audio/video.
4. Apunta la cámara directamente hacia el cuadro físico.

## 🛠️ Tecnologías utilizadas
* [MindAR](https://github.com) - Rastreo de imágenes y reconocimiento de patrones.
* [A-Frame](https://aframe.io) - Framework web para el renderizado 3D y VR.
* GitHub Pages - Hospedaje gratuito del sitio web.
